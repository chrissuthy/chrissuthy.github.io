Software

oSCR
R package for spatial capture-recapture analysis
oSCR is an R package for spatial capture-recapture (SCR) analysis, providing an intuitive multi-session, sex-structured likelihood framework for modelling density, space use, and connectivity from spatial encounter data.
Paper GitHub Tutorials User Group
wildtag.ai
Desktop application for AI-powered camera trap image classification
wildtag.ai is a desktop application for automated species identification from camera trap images. It runs state-of-the-art AI models (DeepFaune and SpeciesNet) locally on your own computer, with no coding required, and includes a built-in interface for reviewing and correcting predictions. DeepFaune (for UK and European wildlife) works fully offline; SpeciesNet (global coverage) downloads on first use.
